Sobre o Projeto

O Gerador de UDI ANVISA é uma solução web desenvolvida para facilitar a criação de códigos GS1 DataMatrix destinados à Identificação Única de Dispositivos Médicos (UDI), atendendo às normativas da ANVISA e aos padrões globais GS1.

Projetado para operar inteiramente client-side, a ferramenta garante alto desempenho, segurança e praticidade para fabricantes, distribuidores e profissionais de rastreabilidade do setor da saúde.

Estrutura do Código Gerado (Ordem dos AIs)

AI Descrição Formato Obrigatório
(01) GTIN-14 14 Números Sim
(17) Data de Validade YYMMDD Sim
(10) Lote de Fabricação Alfanumérico (até 20) Sim
(90) Informação do Usuário / Registro Alfanumérico (até 30) Não
(240) Identificação Adicional Alfanumérico (até 30) Não
(11) Data de Fabricação YYMMDD Não
(21) Número de Série Alfanumérico (até 20) Não
Exemplo GS1 Completo: (01)07891234567890(17)271231(10)LOTE123(90)REG123(240)REF987(11)260724(21)SN123456

Funcionalidades & Arquitetura

  • Validação nativa de checksum GTIN-14
  • Suporte a AI (01), (17), (10), (90), (240), (11) e (21)
  • Leitura e preenchimento via parâmetros de URL
  • Download do código gerado em formato PNG
  • Geração de link parametrizado compartilhável
  • Formatação automática de datas GS1
  • Geração local via BWIP-JS em Canvas

Tecnologias Utilizadas

HTML5 & CSS3

Interface estruturada com CSS Grid, Flexbox e Design System baseado em variáveis CSS.

Vanilla JS (ES6+)

Lógica pura sem frameworks, garantindo leveza, rápida execução e zero dependências pesadas.

BWIP-JS

Biblioteca para compilação exata dos padrões simbólicos do GS1 DataMatrix (ECC200).
